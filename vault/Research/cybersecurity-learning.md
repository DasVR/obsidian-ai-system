# Ethical Hacking Notes

## Rules
- Research only on machines you own or have explicit permission for
- Never touch real systems, networks, or people without authorization
- This is a learning path, not a weapon path

## Learning Roadmap
1. Networking basics (TCP/IP, DNS, HTTP)
2. Linux internals + bash scripting
3. Python for tooling
4. Web app security (OWASP Top 10)
5. CTFs: TryHackMe, Hack The Box, PicoCTF
6. Cert path: CompTIA Security+, maybe PNPT or OSCP later

## Tools to Learn
- nmap, gobuster, dirb
- Burp Suite Community
- Wireshark
- Metasploit (only on lab VMs)
- pwntools, impacket

## Practice Labs
- TryHackMe Pre-Security path
- Hack The Box Starting Point
- DVWA / WebGoat local
- VulnHub VMs
